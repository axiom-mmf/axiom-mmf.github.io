02 — Axiom

Computational design

Geometry generated from engineering rules, so a design can be regenerated when requirements change instead of redrawn.

Start a project →

What you get

  • Rule-driven and voxel-based geometry built on the open-source PicoGK kernel
  • Native Rhino .3dm results, no proprietary viewer
  • A written summary of the rules and inputs behind each output

Typical deliverables

  • Feasibility study: one concept, .3dm and a short report
  • Parametric part families
  • Lattices, infills and conformal internal channels
  • Geometry prepared for additive manufacturing

File formats

Rhino .3dm · STL / 3MF · STEP (where the geometry allows)
